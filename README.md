# 🏨 StayEase – Hotel Management System

A Python-based hotel management system designed to manage essential hotel operations through a console-based interface.

## 📌 Project Overview

**StayEase** is a menu-driven hotel management system developed in Python. It provides different modules for managing hotel administration, front desk operations, accounts, rooms, guests, bookings, and payments.

The system uses text files for persistent data storage.

## ✨ Key Features

### 🏢 System Administration
- Room management
- Guest record management
- Booking management
- Payment record management
- System data loading and management

### 🛎️ Front Desk Management
- Guest check-in
- Guest check-out
- Room availability management
- Booking management
- Guest information handling

### 💰 Accounts Management
- Payment records
- Booking charges
- Financial information management

### 🏨 Room Management
- Room records
- Room availability
- Room status management
- Room information storage
